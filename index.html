New Text File for Finder

Right-click empty space in any Finder folder and create a text file instantly. It sits right beside New Folder.

Download installer (.zip) instructions.txt

What it does

  • Adds New Text File to Finder’s right-click menu on empty space.
  • Creates untitled.txt in that folder, or untitled 2.txt, untitled 3.txt and so on if the name is taken.
  • Selects the new file so you can press Return to rename it.

Install

  1. Download NewTextFileInstaller.zip and unzip it. It contains Install-Right-Click-New-File.command and instructions.txt.
  2. Open Terminal and type bash  (with a trailing space), drag the file onto the window, and press Return. Or run: 
    bash ~/Downloads/NewTextFileInstaller/Install-Right-Click-New-File.command
  3. If Terminal says the Swift compiler is missing, click Install in the popup, wait for it to finish, then run the command again.
  4. When System Settings opens, go to General → Login Items & Extensions → Extensions (or search “Finder extensions”) and tick New Text File.
  5. Right-click empty space in any Finder folder and choose New Text File.

If the menu item doesn’t appear

  • Check the tick box in System Settings.
  • Restart Finder: killall Finder
  • Log out and back in, or run the installer again.

Uninstall

pluginkit -r ~/Applications/NewTextFile.app/Contents/PlugIns/NewTextFileExt.appex
rm -rf ~/Applications/NewTextFile.app
killall Finder

Nothing else is installed on your Mac.

Good to know

  • Requires macOS 12 or later and Apple’s command line tools, which the installer prompts for.
  • The extension is signed for your own Mac only. On another Mac, run the installer there.
  • To create .md or another type, change untitled.txt in the installer script and run it again.
The installer zip is served from /dist/NewTextFileInstaller.zip.
